# Hi, I'm Prashant

I'm a student interested in frontend development and looking for internship opportunities in Korea. My projects explore interactive interfaces, accessibility, and how frontend code connects to a working application.

## Featured projects

### Hangul Lab · Interactive typography

A Korean and English playground for building Hangul syllables. Compare **한**, **물**, and **과**, then change the letters to see how the layout moves. The builder supports keyboard navigation and reduced motion.

**JavaScript · CSS · SVG**

[Live demo](https://9415prash.github.io/hangul-lab/) · [Source code](https://github.com/9415prash/hangul-lab)

### Trello Kanban · Task management

A Trello-inspired workspace with private boards, drag-and-drop cards, labels, checklists, and search. The repository includes local setup instructions and API and browser tests.

**React · TypeScript · Bun · SQLite**

[Source code and setup](https://github.com/9415prash/trello-kanban)

### Movie Lab · Vue and API integration

A Vue coursework project that uses the TMDB API to display movie data. The live page requires a TMDB API key to fetch data.

**Vue · Vite · TMDB API**

[Live demo](https://9415prash.github.io/movie-lab/) · [Source code and setup](https://github.com/9415prash/movie-lab)
